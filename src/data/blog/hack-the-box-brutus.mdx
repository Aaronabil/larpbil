# Write-Up Hack The Box Brutus

### Skenario

In this very easy Sherlock, you will familiarize yourself with Unix auth.log and wtmp logs. We'll explore a scenario where a Confluence server was brute-forced via its SSH service. After gaining access to the server, the attacker performed additional activities, which we can track using auth.log. Although auth.log is primarily used for brute-force analysis, we will delve into the full potential of this artifact in our investigation, including aspects of privilege escalation, persistence, and even some visibility into command execution.

### Task 3

Identify the UTC timestamp when the attacker logged in manually to the server and established a terminal session to carry out their objectives. The login time will be different than the authentication time, and can be found in the wtmp artifact.

Answer: 2024-03-06 06:32:45

Explain: Karena disoal disuruh cari didalam file wtmp, jadi saya menganalisa file wtmp, saya menggunakan perintah

```bash
utmpdump wtmp
```

![screenshot](/blog/hack-the-box-brutus/img-04.png)

disini saya mencari manual login yang berarti interactive shell dan dari file wtmp terdapat

`[7] [02549] [ts/1] [root] [pts/1] [65.2.161.68] [2024-03-06T06:32:45,387923+00:00]`

dan

`[7] [02667] [ts/1] [cyberjunkie] [pts/1] [65.2.161.68] [2024-03-06T06:37:35,475575+00:00]`

karena type \[7\] itu adalah USER. Pertanyaannya yang mana yang manua login? login dari cyberjunkie terlihat seperti user interaktif (attacker foothold), yang artinya login dari root lah yang merupakan manual login jadi UTC Timestampnya adalah 2024-03-06 06:32:45

### Task 4

SSH login sessions are tracked and assigned a session number upon login. What is the session number assigned to the attacker's session for the user account from Question 2?

Answer: 37

Explain: Dari wtmp, attackers login sebagai root yang artinya SSH login berhasil dan terminal dibuat. Untuk mencari session number dari SSH login disini saya menggunakan

```bash
grep "New session" auth.log
```

![screenshot](/blog/hack-the-box-brutus/img-05.png)

Disini terdapat 3 session yang sama dari root, nah disini saya tinggal mencocokan waktunya saja, karena soal menanyakan dari question 2 dan jawaban dari question 2 itu adalah 06:32:45 jadi saya cocokan saja dan session numbernya adalah 37 karena waktunya sama
