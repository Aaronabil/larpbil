# WebStrike Lab

### Scenario

A suspicious file was identified on a company web server, raising alarms within the intranet. The Development team flagged the anomaly, suspecting potential malicious activity. To address the issue, the network team captured critical network traffic and prepared a PCAP file for review.

Your task is to analyze the provided PCAP file to uncover how the file appeared and determine the extent of any unauthorized activity.

### Pendahuluan

Disini saya mendapatkan sebuah virtual machine yang di dalam file manager dibagian desktop terdapat 2 folder, folder **Artifacts** dan folder **Tools**, folder Artifacts berisi file **WebStrike.pcap** dan folder Tools berisi aplikasi-aplikasi yang bisa membantu saya dalam menjawab soal-soal

### Question 1

Identifying the geographical origin of the attack facilitates the implementation of geo-blocking measures and the analysis of threat intelligence. From which city did the attack originate?

Answer: Tianjin

Explain: Pertama saya buka file WebStrike.pcap di wireshark dan mencari tahu mana ip yang korban dan attackers, disini saya menemukan bahwa ip attackers adalah **`117.11.88.124`**** **karena ip tersebut melakukan request ke destination `24.49.63.79` yang merupakan ip korban

![screenshot](/blog/webstrike-lab/img-01.png)

Jadi saya menggunakan ip attackers untuk mengetahui dari kota manakah serangan berasal

```bash
curl -s http://ip-api.com/json/117.11.88.124
```

Output:

![screenshot](/blog/webstrike-lab/img-02.png)

Disini terlihat bahwa attackers berasal dari kota Tianjin
